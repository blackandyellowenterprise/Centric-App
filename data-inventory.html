File Format

CASE Format (Consortium of State Academic Standards Exchange)

  • Columns: Item Type, Sequence, Human Code, Full Statement, Ed. Level, Last Modified
  • Hierarchy: Grade Level → Strand → Standard → Benchmark → Component
  • Naming: [State Name] [Subject Area]-CASE-items.csv

Centric Format

  • Format: Excel workbooks with multiple sheets
  • Organization: Grade level tabs, strands as rows
  • Metadata: Proficiency levels (Basic, Intermediate, Advanced)
