# Centric Project Management Platform

**AI-assisted curriculum development platform for the Centric Learning project.**

This repository implements automated workflows that transform raw curriculum inputs (standards, meeting transcripts, learnings) into production-ready educational assets, enabling Subject Matter Experts (SMEs) to focus on review and approval rather than content creation.

## Core Value Proposition

| Current | With Centric |
|---------|-------------|
| SMEs create content from scratch | AI generates draft content from standards |
| Weeks to produce curriculum | Days to produce and review |
| Manual, unstructured review | Automated review checklists and gates |
| Content drift and inconsistency | Centralized decisions log and standards enforcement |
