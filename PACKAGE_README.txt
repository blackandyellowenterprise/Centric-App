QUICK INSTALLATION
================================================================================

1. EXTRACT THIS ZIP FILE
   unzip Centric-Learning-Handoff-Package.zip
   cd Centric-Learning-Handoff-Package

2. INSTALL DEPENDENCIES
   pip install -r requirements.txt

3. DOWNLOAD STANDARDS DATA
   # Get "Centric Courses Strand.zip" from repository
   unzip "Centric Courses Strand.zip" -d extracted_data

4. CONFIGURE API KEY
   cp .env.example .env
   # Edit .env and add your ANTHROPIC_API_KEY

5. RUN THE SERVER
   python3 main.py

6. OPEN WEB INTERFACE
   # Double-click centric-app.html in your browser
   # Or visit: http://localhost:8000/docs

✅ DONE! You're ready to use the app.
